# AutoCare v1.4 — Asistente IA

## Objetivo

Definir la capa de inteligencia contextual del vehículo.

## Flujo

Usuario → API IA → Contexto del vehículo → Motor de recomendaciones → Respuesta explicada.

## Fuentes de contexto

- Datos del vehículo.
- Historial de mantenimiento.
- Documentos aportados.
- Lecturas OBD.
- Alertas generadas.
- Incidencias registradas por el usuario.

## Principios

- Explicar siempre el motivo de una recomendación.
- Diferenciar datos reales de predicciones.
- Pedir confirmación antes de crear intervenciones.
- Mantener trazabilidad del origen de cada aviso.

## Próximos pasos

- Endpoint del asistente.
- Integración móvil.
- Pruebas con vehículos reales.
