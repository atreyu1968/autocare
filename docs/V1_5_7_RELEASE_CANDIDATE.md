# AutoCare v1.5.7 — Release Candidate

## Objetivo
Preparación de una versión candidata previa a pruebas externas.

## Validaciones previstas

- instalación limpia;
- configuración inicial;
- comprobación de servicios;
- verificación de comunicación entre módulos;
- revisión de experiencia de usuario.

## Criterios de paso a beta externa

- despliegue reproducible;
- documentación disponible;
- registro de incidencias preparado;
- recuperación ante errores documentada.

## Próximos pasos

- pruebas funcionales completas;
- corrección de incidencias;
- preparación de versión estable.
