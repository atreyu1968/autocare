# AutoCare v1.8.6 — Diagnóstico inicial y estado del sistema

## Objetivo
Definir el sistema de diagnóstico inicial tras la primera ejecución.

## Funciones

- Estado general de la aplicación.
- Verificación de componentes.
- Comprobación de conexión con servicios.
- Validación de base de datos.
- Estado de integración OBD-II.
- Registro inicial de incidencias.

## Flujo

Instalación

↓

Primer arranque

↓

Diagnóstico automático

↓

Informe de estado

↓

Sistema preparado para pruebas reales

## Criterios de aceptación

- Diagnóstico ejecutable.
- Errores identificables.
- Estado del sistema visible para el usuario.
- Base preparada para soporte técnico.
