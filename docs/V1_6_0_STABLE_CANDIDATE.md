# AutoCare v1.6.0 — Stable Candidate

## Objetivo
Preparación del paso desde beta hacia una versión estable.

## Validaciones requeridas

- Instalación reproducible.
- Servicios correctamente iniciados.
- Persistencia de datos validada.
- Gestión de usuarios comprobada.
- Flujo de vehículo operativo.
- Mantenimiento y alertas verificadas.
- Integración IA validada.
- Documentación disponible.

## Criterio de publicación
La versión estable solo se publicará tras superar pruebas funcionales completas y validación con usuarios reales.

## Próximos pasos
- pruebas finales;
- corrección de incidencias;
- generación de release estable.
