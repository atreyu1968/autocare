# AutoCare Beta 1.4.7 — Guía de instalación y despliegue

## Objetivo
Preparar la instalación de la versión beta para pruebas reales.

## Componentes

- Backend AutoCare
- Aplicación móvil Android
- Módulos IA
- Diagnóstico OBD
- Sistema de alertas

## Instalación backend

1. Configurar variables de entorno.
2. Preparar base de datos.
3. Instalar dependencias.
4. Iniciar servicio API.

## Aplicación móvil

- Configurar URL de API.
- Registrar dispositivo.
- Validar autenticación.

## Pruebas iniciales

- Alta de usuario.
- Registro de vehículo.
- Carga documental.
- Generación de alertas.
- Consulta IA.
- Lectura OBD.

## Producción

Antes de publicar se debe completar:

- pruebas de seguridad;
- copias de seguridad;
- monitorización;
- validación con usuarios piloto.
