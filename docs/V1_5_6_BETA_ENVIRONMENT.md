# AutoCare v1.5.6 — Entorno beta completo

## Objetivo
Preparación del primer entorno beta controlado antes de la entrega a usuarios reales.

## Elementos previstos

- entorno reproducible;
- configuración beta documentada;
- comprobación de servicios;
- validación de comunicación entre módulos;
- preparación de pruebas funcionales.

## Criterios de aceptación

- instalación repetible;
- servicios accesibles;
- errores identificables mediante logs;
- documentación suficiente para pruebas.

## Flujo beta

Usuario beta → Instalación → Validación → Uso real → Recogida de incidencias → Correcciones.
