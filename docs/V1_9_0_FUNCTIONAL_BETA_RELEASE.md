# AutoCare v1.9.0 — Beta funcional completa

## Objetivo
Consolidar la versión beta funcional con todos los módulos principales preparados para pruebas controladas.

## Validaciones incluidas

- Instalación y primer arranque.
- Configuración inicial de usuario.
- Gestión de vehículos.
- Registro de mantenimiento.
- Sistema de alertas.
- Integración OBD-II preparada.
- Historial y persistencia de datos.
- Flujo completo de usuario.

## Checklist de liberación beta

```
Instalación correcta
        ↓
Configuración inicial
        ↓
Alta de vehículo
        ↓
Uso diario
        ↓
Registro de incidencias
        ↓
Correcciones finales
```

## Criterios de aceptación

- Funciones principales operativas.
- Errores críticos controlados.
- Documentación disponible.
- Preparado para pruebas con usuarios seleccionados.
