# AutoCare v1.6.2 — Preparación de Release estable

## Objetivo
Preparar la transición desde candidato estable a versión instalable para usuarios reales.

## Validaciones

- Instalación reproducible.
- Configuración documentada.
- Servicios verificados.
- Flujos principales comprobados.
- Control de incidencias.

## Checklist final

- Backend operativo.
- Aplicación cliente funcional.
- Gestión de vehículos.
- Mantenimiento.
- Diagnóstico.
- Alertas.
- Asistente IA.
- Documentación de usuario.

## Criterio de liberación

La versión solo se marcará como estable cuando pueda instalarse desde cero y superar las pruebas de aceptación definidas.
