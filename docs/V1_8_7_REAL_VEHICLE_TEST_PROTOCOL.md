# AutoCare v1.8.7 — Protocolo de pruebas reales con vehículo

## Objetivo
Definir el procedimiento para validar AutoCare en un entorno real con un vehículo físico.

## Pruebas principales

- Alta de vehículo real.
- Configuración inicial del usuario.
- Conexión OBD-II.
- Lectura de datos disponibles.
- Registro de mantenimiento.
- Generación de avisos.
- Validación del flujo completo de usuario.

## Flujo de prueba

Vehículo registrado

↓

Conexión OBD-II

↓

Lectura de información

↓

Registro en aplicación

↓

Validación de alertas

↓

Informe de resultados

## Criterios de aceptación

- Conexión estable.
- Datos correctamente almacenados.
- Información visible para el usuario.
- Incidencias registradas y clasificadas.
