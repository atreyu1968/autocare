# AutoCare Beta 1.4.9 — Release Plan

## Objetivo
Preparación de la primera beta funcional para usuarios reales.

## Áreas verificadas

- Backend API.
- Gestión de vehículos.
- Historial de mantenimiento.
- Alertas inteligentes.
- Diagnóstico OBD-II.
- Health Score.
- Asistente IA contextual.
- Aplicación móvil.
- Preparación Android Auto.

## Fase beta

1. Instalación inicial.
2. Registro de vehículo.
3. Carga de historial.
4. Generación de alertas.
5. Pruebas OBD.
6. Validación recomendaciones IA.
7. Recogida de incidencias.

## Criterios para v1.5 estable

- Sin errores críticos.
- Flujos principales validados.
- Seguridad revisada.
- Copias de seguridad configuradas.
- Documentación completa.
