# AutoCare v1.7.0 — Primera versión candidata operativa

## Objetivo
Preparación de la primera versión candidata operativa antes de pruebas con usuarios reales.

## Validaciones previstas

- Instalación reproducible.
- Arranque correcto de servicios.
- Configuración inicial.
- Validación de módulos principales.
- Revisión de documentación.

## Criterio de paso

La versión podrá considerarse lista para instalación cuando supere:

1. Prueba de instalación limpia.
2. Verificación funcional completa.
3. Ausencia de errores críticos.
4. Validación en dispositivo real.

## Estado

Candidata operativa en preparación.
