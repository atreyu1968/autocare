# AutoCare v1.4.4 - Integración IA + Android Auto

## Objetivo
Preparar la comunicación entre el asistente IA de AutoCare y la experiencia móvil durante la conducción.

## Funciones previstas

- Consulta rápida del estado del vehículo.
- Resumen de alertas prioritarias.
- Avisos de mantenimiento pendientes.
- Respuestas breves adaptadas a conducción.

## Flujo

Vehículo -> API AutoCare -> Contexto IA -> Aplicación Android -> Android Auto.

## Restricciones

La información mostrada durante conducción debe ser breve y segura, evitando operaciones complejas.
