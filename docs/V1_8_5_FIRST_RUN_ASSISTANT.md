# AutoCare v1.8.5 — Primera ejecución asistida

## Objetivo
Definir el flujo inicial de puesta en marcha para un usuario tras instalar AutoCare.

## Asistente inicial

1. Verificación del entorno.
2. Creación del usuario administrador.
3. Configuración básica de preferencias.
4. Alta del primer vehículo.
5. Preparación de conexión OBD-II.
6. Validación de comunicación con servicios.

## Flujo de primer inicio

```
Instalación completada
        ↓
Inicio de aplicación
        ↓
Asistente de configuración
        ↓
Usuario administrador
        ↓
Vehículo inicial
        ↓
Configuración OBD
        ↓
Sistema operativo
```

## Validaciones

- Usuario creado correctamente.
- Datos persistentes disponibles.
- Vehículo registrado.
- Servicios accesibles.
- Estado inicial generado.

## Resultado esperado

El usuario debe poder acceder a la aplicación con un vehículo configurado y preparado para pruebas reales.
