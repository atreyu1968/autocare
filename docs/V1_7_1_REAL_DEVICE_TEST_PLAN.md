# AutoCare v1.7.1 — Plan de pruebas en dispositivo real

## Objetivo
Preparar la primera validación práctica sobre dispositivo móvil y entorno real.

## Checklist

- Instalación de aplicación.
- Configuración inicial de usuario.
- Alta de vehículo.
- Registro de mantenimiento.
- Prueba de alertas.
- Prueba de conexión OBD-II.
- Validación del asistente IA.
- Registro de incidencias.

## Criterio de aceptación

La versión será candidata a beta cuando los flujos principales funcionen sin errores críticos.
