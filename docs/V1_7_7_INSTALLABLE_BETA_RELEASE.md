# AutoCare v1.7.7 — Preparación de versión beta instalable

## Objetivo
Definir el paquete previo a la primera instalación externa controlada.

## Alcance
- Paquete reproducible.
- Configuración inicial guiada.
- Verificación automática de dependencias.
- Control de versión.
- Documentación de instalación.

## Flujo de entrega

Instalación limpia

↓

Configuración inicial

↓

Validación automática

↓

Pruebas funcionales

↓

Entrega beta

## Criterios previos

- No existen errores críticos conocidos.
- Los servicios principales arrancan correctamente.
- La documentación permite una instalación independiente.
- Existe procedimiento de recuperación ante fallos.
