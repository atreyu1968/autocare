# AutoCare v1.5.8 — Manual de usuario

## Objetivo
Guía inicial para usuarios beta.

## Primer uso
- Crear cuenta.
- Registrar vehículo.
- Añadir datos básicos.
- Configurar mantenimiento.

## Diagnóstico
La aplicación permite consultar el estado del vehículo mediante datos registrados, mantenimiento y diagnósticos compatibles.

## Asistente IA
El asistente utiliza el contexto disponible del vehículo para explicar avisos y recomendaciones.

## Alertas
Las alertas muestran incidencias detectadas y acciones recomendadas.
