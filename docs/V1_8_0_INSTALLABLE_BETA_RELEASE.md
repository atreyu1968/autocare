# AutoCare v1.8.0 — Primera versión beta instalable

## Objetivo

Preparación de la primera versión beta instalable de AutoCare para pruebas controladas.

## Alcance

- Paquete beta reproducible.
- Instalación documentada.
- Configuración inicial guiada.
- Validación automática de componentes.
- Checklist de aceptación.

## Flujo de instalación

1. Preparación del entorno.
2. Instalación de dependencias.
3. Configuración inicial.
4. Arranque de servicios.
5. Verificación automática.
6. Pruebas funcionales.

## Validaciones mínimas

- Aplicación inicia correctamente.
- Datos persistentes disponibles.
- Gestión de vehículos operativa.
- Módulos principales accesibles.
- Registro de incidencias preparado.

## Estado

Versión beta candidata para pruebas controladas antes de release estable.
