# AutoCare v1.7.9 — Paquete de prueba real

## Objetivo
Preparar la entrega de un paquete candidato para pruebas reales controladas.

## Contenido previsto

- Instalación reproducible.
- Configuración inicial asistida.
- Verificación automática de servicios.
- Documentación de usuario y administrador.
- Registro de incidencias.

## Flujo de instalación

1. Preparar entorno.
2. Instalar componentes.
3. Ejecutar validación inicial.
4. Configurar usuario y vehículo.
5. Realizar pruebas funcionales.

## Criterios de aceptación

- Arranque correcto.
- Persistencia de datos funcional.
- Módulos principales accesibles.
- Errores críticos identificados y gestionados.
